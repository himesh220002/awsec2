Case File 001

How It
Ships

A learning build: an Express blog on port 8080, containerized, pushed to Docker Hub by CI and pulled onto EC2 by CD — all on every push to master.

The Run

01

Push

Commit lands on master at github.com/himesh220002/awsec2.

02

Docker CI

GitHub Actions logs into Docker Hub, builds the image and pushes :latest.

03

Docker CD

Fires only after CI succeeds — SSHs into EC2, pulls the image, stops the old container and starts the new one on port 8080.

Loadout

EXPRESS :8080 DOCKER GITHUB ACTIONS DOCKER HUB AWS EC2 TAILWIND THREE.JS D3
